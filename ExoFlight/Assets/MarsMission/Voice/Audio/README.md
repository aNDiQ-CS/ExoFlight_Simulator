# Озвучка миссии Марса

17.11.2026: добавлены 71 готовая запись из папки «Давид Игра». Для каждой реплики выбран
последний полный соответствующий дубль. Исходные записи сохранены без изменений.
Таблица соответствий и исключения: `docs/MARS_VOICE_MATCHING.md` в корне репозитория.
S1-07 (№30) и S5-03 (№96) стоит проверить на слух из-за неоднозначного распознавания отдельных слов.

Положите сюда готовые записи. Имя каждого файла — точно из столбца «Файл» исходного сценария:

- `vo_s0_01_ai.wav` — приветствие ИИ;
- `vo_s0_03_cmd.wav` — брифинг командира;
- `vo_s3_01_ai.wav` — подтверждение захвата марсохода;
- `vo_s6_08_cmd.wav` — успешное завершение.

Все 71 ожидаемое имя перечислены в соседнем `Scenario.json` и в `docs/mars-voice-cues.tsv`.

После импорта Unity автоматически обновляет `MarsVoiceLibrary.asset`. Перетаскивать клипы
в каждый триггер не нужно. Это работает и для замены, перемещения и удаления записи.
Подпапки разрешены. Для одного имени оставьте один готовый файл; если дублей несколько,
автоматический выбор намеренно отключён и в Console будет сообщение.

Если актёр прислал `vo_s0_01_ai_t2.wav`, выберите последний полный дубль той же реплики и переименуйте его
в `vo_s0_01_ai.wav`. Номер дубля не входит в ключ готовой записи.
Можно использовать WAV, OGG или MP3 с тем же именем до расширения, которые Unity импортирует как AudioClip.
Исходный сценарий рекомендует WAV, 48 кГц, 24 бит, моно.

Резервная команда: **ExoFlight → Марс: переподключить озвучку**.
Сначала дождитесь окончания импорта, затем запускайте Play Mode. Привязки сохраняются
в ScriptableObject и работают в сборке игры. Копирование файлов уже в собранную игру не поддерживается.

Пока записи нет, её текст с ID выводится в Console, а канал выдерживает короткую паузу.
Это не подменяет запись синтезированным голосом и не блокирует прохождение.
